# SimCarDiag Auto

Version de SimCarDiag faite pour les autoradios Android (écran large, en voiture).

- **Interface simplifiée** : une barre de 5 grosses tuiles (Accueil, Conduite, Diagnostic, Carburant, Plus).
  Trajets, véhicule et réglages sont regroupés dans « Plus ».
- **Réglée pour l'autoradio dès l'installation** : thème sombre, plein écran, paysage, disposition autoradio,
  démarrage avec l'appareil, connexion au boîtier dès qu'il est détecté, boutons musique.
- **Liaison Bluetooth adaptative** : si le boîtier se tait deux fois en moins de 3 minutes, l'appli essaie
  une autre façon d'ouvrir la liaison (sécurisée, non sécurisée, canal direct) et garde celle qui tient.
- Mises à jour proposées depuis les versions publiées de ce dépôt.

Identifiant Android : `fr.simcardiag.auto` (s'installe à côté de SimCarDiag sans la remplacer).

Important : n'utilisez pas SimCarDiag (ou Torque) en même temps sur le même appareil, un boîtier OBD
ne parle qu'à une seule appli à la fois.
